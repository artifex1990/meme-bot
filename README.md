# start

Рабочая папка мем-бота.

Команды и файлы из презентации `python_bot.html` выполняются здесь, по порядку слайдов.

Папка `meme-bot` рядом уже собрана. Это пример готового результата. В `start` её не копируют.

Из примера переносится только `fonts/font.ttf`, на том слайде, где речь про шрифт.
